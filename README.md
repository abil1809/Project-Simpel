# 🌱 Belajar Git: Landing Page

Project latihan untuk mempelajari workflow Git dan GitHub dari nol,
dibuat dengan **HTML, CSS, dan JavaScript murni** (tanpa framework).

## Fitur

- 🌙 Tombol ganti tema terang/gelap
- 💡 Generator tips Git acak
- 🔢 Penghitung klik

## Cara menjalankan

1. Clone repo ini:
   ```bash
   git clone https://github.com/USERNAME/belajar-git-web.git
   ```
2. Buka folder project, lalu klik dua kali `index.html`.

Tidak perlu install apa pun.

## Teknologi

- HTML5
- CSS3 (CSS variables)
- JavaScript (vanilla)

## Yang saya pelajari

- `git init`, `add`, `commit`, `push`
- Menulis pesan commit yang jelas
- Alur branch dan merge
